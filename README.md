# OTICS-Security
# OT Network Segmentation

## Overview

This project demonstrates Operational Technology (OT) network segmentation concepts using the Purdue Enterprise Reference Architecture.
The objective is to reduce risk by separating industrial control systems from business IT networks while maintaining operational requirements.

## Goals

- Separate IT and OT environments
- Limit unnecessary communications
- Improve visibility of industrial assets
- Support cybersecurity best practices

## Purdue Model

### Level 5
Enterprise Network

### Level 4
Business Systems

### Level 3
Operations Management

### Level 2
Supervisory Control (SCADA/HMI)

### Level 1
Basic Control (PLCs)

### Level 0
Physical Process

## Security Recommendations

- Implement network segmentation
- Restrict remote access
- Monitor OT network traffic
- Maintain asset inventories
- Follow least privilege principles
